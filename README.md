## Setup

In the terminal, make sure the current working directory is in the project itself and then run these:

```
python -m venv .venv
```

```
python -m pip install -r requirements.txt
```


## Run

> Run this command if 'python app.py' fails. You can then try running python app.py again after this.

```
source .venv/bin/activate
```


```
python app.py
```


Once it runs successfully without errors, you can then open the system through this link:


<http://127.0.0.1:5000>
